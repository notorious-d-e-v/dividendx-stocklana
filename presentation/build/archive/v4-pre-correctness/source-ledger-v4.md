## Stage boundary

- Working now: approved interface and historical calculator.
- Planned next: one shared program and issuer readers for xStocks, Backpack and Ondo, with isolated vaults and representative test profiles. Only the KOx reference has a complete source-verified historical replay today.
- Eligibility remains conditional. A token needs documented dividend rights, usable event data, compatible custody and tested transfers. Solana presence or Scaled UI alone is insufficient.
- Roadmap: more eligible Solana stocks, then reviewed support for assets on other networks. Cross-chain custody, settlement and messaging are unimplemented.
- No deployed protocol, completed trade, organic liquidity, partnership, guaranteed yield, or protected dollar principal is claimed.
